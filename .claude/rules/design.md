# Surveilled design rules

Surveilled is a daily logic puzzle set in the Ministry of Truth, where hidden CCTV cameras watch every corridor. Each day brings four records, played in order; filing the fourth topples the government. Every screen is a filled-in government form: cold, square, typed, stamped. Once a record's orders are read, everything happens on a sheet of paper rolled into a typewriter, and the page is exactly one screen tall: nobody scrolls the page, on a phone or a PC. Follow these rules for any UI, styling, copy or asset change.

## Tokens (use these exact values, as CSS variables)

```css
:root {
  --concrete: #c3c7bf; /* page background */
  --paper: #e9ebe4; /* hidden cells, buttons, panels */
  --cleared: #d6d9d1; /* cells that show a number */
  --ink: #1b1f1d; /* all text, board frame, true (black) numbers */
  --slate: #3a413d; /* walls only, never text */
  --muted: #4a514c; /* secondary text (replaces old #545c56, which failed contrast) */
  --party: #b3261e; /* Party: red numbers, stamps, strikes, primary button fill */
  --party-text: #9a2019; /* red text under 24px on concrete */
  --gaze: #e4c24f; /* sight-line highlight on hidden cells */
  --gaze-number: #d9c46e; /* sight-line highlight on numbered cells */
  --siren: #2b4fd6; /* police blue: the loss siren only, never text or UI */
  --dossier: #e3d3af; /* manila: the folder only, as the base of its shades */
  --coffee: #6f4520; /* the coffee ring on the orders and the day's last report, always translucent */

  --font-display:
    "Big Shoulders Stencil Display", Impact, "Arial Narrow", sans-serif;
  --font-digit: "Big Shoulders Display", Impact, "Arial Narrow", sans-serif;
  --font-body: "Courier Prime", "Courier New", Courier, monospace;
  --font-typed: "IBM Plex Mono", "Courier Prime", "Courier New", monospace;

  --space-board: 3px;
  --space-1: 4px;
  --space-2: 6px;
  --space-3: 10px;
  --space-4: 14px;
  --space-5: 16px;
  --cell-max: 72px;
  --cell-floor: 36px; /* the smallest a board cell may get; 44px on touch screens (pointer: coarse) */
  --sheet-max: 500px;
  --shadow-tile: inset 0 -4px 0 rgba(27, 31, 29, 0.16);
  color-scheme: light;
}
```

Never hard-code a color, font or spacing value that has a token. Never add a new color without asking.

In the React app these tokens live in `frontend/src/index.css` and reach Tailwind through `@theme inline`: colors as `bg-concrete`, `text-party`, `border-ink` and so on (Tailwind's default palette is removed), the four faces as `font-stencil`, `font-condensed`, `font-typewriter` and `font-board`, and the other tokens as `gap-(--space-4)`, `max-w-(--sheet-max)` and `shadow-(--shadow-tile)`. The animations are `motion-safe:animate-thunk` (with `motion-safe:animate-thud` on the stamped cell), `motion-safe:animate-snap` (a camera mark), `motion-safe:animate-blink`, the `motion-safe:transition-colors` sweep on cells, the cell opening (`motion-safe:animate-keystrike` on the digit and `motion-safe:animate-platen` on the cell), the paper feed (`motion-safe:animate-feed`), and the alarms: `motion-safe:animate-shake`, `motion-safe:animate-alarm`, `motion-safe:animate-siren-red` and `motion-safe:animate-siren-blue` (see `AlarmOverlay.tsx` and `ShakeOnAlarm.tsx`).

## The ten rules

1. **One theme.** No dark mode, no seasonal reskins. Concrete ground, paper for anything touchable, ink for anything readable.
2. **Red means the Party, nothing else.** `--party` is only for Party records (red numbers), the red corner tick, False stamps, verdicts, strikes and the single primary button per view. Never for decoration, links, errors that aren't strikes, or promos.
3. **Black is the truth.** Numbers the player uncovers are always `--ink`. Never tint or fade a true number.
4. **No rounded corners.** `border-radius: 0` everywhere. The only curves are the camera icon's lens, the folder's wax seal, the coffee ring on the orders and the day's last report, and the typewriter's round keys, platen knobs, paper-bail rollers and the typebars' curved segment.
5. **The board is the hero.** Nothing overlaps it: no ads, banners, tooltips, toasts or modals, and no dimming overlays. Messages go below it. The one exception is the alarm light from rule 9, which never takes input and never hides the board for more than a moment. Two sheets take the record's place in the typewriter instead of covering it: the Archivist's report, fed in once a record closes (after a beat to see the board; after a loss, once the siren lights are over) and taken out with "Back to record" or Escape, brought back with "Show report"; and the rules card, which the player feeds in on purpose with the "?" and takes out at will. During a record, the clock keeps running while the rules are in. Training records are played on their own screen, never over a record.
6. **Raised means hidden.** Only hidden cells get `--shadow-tile`. Numbered cells and walls are flat. No other shadows, no gradients, no blur. The one exception is fresh ink (rule 9): a hard, unblurred spread of a typed digit's or a False stamp's own colour that dries away in a third of a second.
7. **Four faces, four jobs.** Stencil (`--font-display`, 900, uppercase) names things: verdicts, section heads, the folder's heading and stamps. Condensed (`--font-digit`, 800, tabular-nums) shows numbers off the board: the status row's counts, the clock, the standing. Typewriter (`--font-body`) explains, and types every line on the sheet above the board (the letterhead, the level tabs, the status labels). Typed (`--font-typed`, IBM Plex Mono 600, an electric office typewriter's clean, even strike) types every number on the board (`Digit` in `BoardCell.tsx`), black and red alike, each set slightly off true like a typebar (a small fixed rotation and 1px offset picked by cell index). Load each Google font with its own `<link>` so one failure doesn't break the others.
8. **Yellow is attention, never state.** `--gaze` only shows what a selected number can see. Don't use it for warnings or success.
9. **Ten moments of motion.** The False stamp thunk (it comes down from 2×, overshoots into the paper wet with ink, settles and dries in 0.3s, and the cell dips 3px as it lands; only the stamp just made thunks, never one already on the board), a camera mark snapping on (the icon lands with a 12° twist, overshoots and settles in 0.22s, and the cell dips 2px; the Open hint's mark too), the sight-line sweep (45ms delay per cell of distance, outward), the blinking hint outline, a cell opening (`Keystrike` in `BoardCell.tsx`, timed by `revealDelays` in `game/board.ts`: the number is typed in like a typewriter key. It lands at once with no fade, squashed into the paper and heavy with fresh ink, springs back past true and settles in about 0.15s, and the ink dries to the face's own weight by 0.36s; the cell dips 2px and back as the platen takes the blow. A cascade follows the flood outward from the opened cell through the open cells, around walls, at the sweep's 45ms a step, each cell up to 12ms early or late like a typist's rhythm, and keeps its paper and raised edge until its turn. An Open hint that marks a camera types its icon the same way), the paper feed (a fresh sheet in the typewriter: a record, a training record, the report or the rules card rises from behind the platen in 0.35s, a translate only), opening the folder, the orders unfolding (from the top, like a letter opened out of its folds, in 0.5s; they arrive already typed), and two alarms. Training records use the board's own motion and nothing more. Opening the folder takes about 1.2s: the seal and ribbon break, the cover swings open towards the player (rotating on its left hinge and fading as it passes edge-on), the orders lift out; then they unfold on the desk. A strike shakes the board once and pulses a red glow around the screen edge once. A loss runs the siren: `--party` red and `--siren` blue lights alternating from the top corners plus a split light bar, four cycles of 0.8s. The alarms are the only place gradients and glow are allowed. Flashing stays at or under 1.25 per second per light (WCAG 2.3.1 allows three) and never fills the screen with saturated red. Nothing else animates. Wrap everything in `@media (prefers-reduced-motion: no-preference)`; with reduced motion the alarms are not rendered at all.
10. **Every word is a form.** Short, flat, bureaucratic second-person sentences. No exclamation marks, no emoji, no praise, no jokes.

## The board

- Square cells (`aspect-ratio: 1`), `--space-board` gap showing `--ink` as the grid. The board takes the sheet's spare height (`BoardGrid.tsx`, a size container): its width is the smallest of the full width, the width at which `--rows` square cells fit the height, and `cols * var(--cell-max)`. It never shrinks below `--cell-floor` per cell (44px on touch screens, 36px with a mouse); only below that does the sheet scroll (an iPhone SE on level IV). No more than 7 columns on mobile.
- Cells are plain fills. Dev builds can draw every cell but a wall as an office cubicle seen from above (`Cubicle` in `BoardCell.tsx`) with the "Show cubicles" toggle in Developer tools, which sets `data-cubicles` on `<html>` for the `cubicles` Tailwind variant. With it on, opened cells use `--concrete` so they stay distinct from hidden ones. Production never renders it.
- Each cell state has one look:
  - hidden: `--paper`, `--shadow-tile`
  - wall: `--slate`, flat
  - observation: `--cleared`, `--ink` typed digit (`--font-typed`, set slightly off true, like every board digit)
  - Party record: `--cleared`, `--party` digit, 9px red corner triangle top-left
  - marked camera: `--paper`, `--ink` camera icon
  - exposed camera: `--party` fill, `--paper` icon
  - once the record closes: unmarked cameras show a `--party` icon; wrong marks get a `--party` strike-through
- Interaction states are outlines, never fills: selected number = 3px solid `--ink` outline (offset -3px); hinted cell = 3px dashed `--party` outline (offset -4px); keyboard focus = 3px solid `--party`.
- Board digit size: `calc(100cqi / var(--cols) * .56)`, with the board as a size container.

## Layout

- **Two places.** A record not yet started is on the **desk** (`Desk.tsx`): first a sealed folder: concrete, one column, `max-width: var(--sheet-max)`, gutters `--space-5`, sections `gap: var(--space-4)`, fitting one screen (the folder is sized by the screen's height as well as its width). The orders are on the desk too (exactly one screen tall, the letter scrolling inside itself between the letterhead and its buttons). Everything after them is the **typewriter** (`TypewriterFrame.tsx`): `h-dvh`, a sheet of `--paper` (1.5px `--ink` edge on top and sides, `max-width: var(--sheet-max)`, gutters `--space-2` on phones) rising out of the machine at the foot of the screen. The page never scrolls; a sheet longer than the space (the orders, the report) scrolls inside the paper. Developer tools sit below the fold in dev builds only.
- **Desk (a record not yet opened):** the letterhead line over a 3px `--ink` rule, then the sealed folder under a "Sealed record · Open on receipt." heading, then exactly two buttons side by side: "Open record" (primary) and "How to play", with one muted line below ("Read your orders first. The clock starts when you start the operation."), then the cookie notice (until acknowledged) and the privacy link at the foot. "How to play" plays training record I, then leads on through IV. "Open record" opens the folder, and its **operation orders** unfold on the desk in its place. "Start operation" under them feeds the record's sheet into the typewriter. Every record of the day arrives this way, so "Next record" leads to the next sealed folder.
- **The typewriter (`Machine.tsx`):** seen from the typist's seat, in black enamel from existing tokens only (no new colour). From the top: the paper bail across the sheet's foot (a thin `--slate` bar with two small rollers), the platen (an `--ink` roller with `--slate` edges and one highlight line, a round knob at each end), then the `--ink` body with a 2px `--slate` top edge. Under the platen lies the fan of typebars (`Typebars` in `Machine.tsx`): 36 thin bars resting in a curved segment, all pointing up at the typing point, in `--paper` at 30–40% like worn steel; the keys sit in front of their outer ends. The body holds the cookie notice until it is acknowledged (the privacy link under the keys hides meanwhile, since the notice links there too), one row of keys between two 48px square function tabs (the sound switch on the left; the "?" on the right during a record, held down with a `--paper` face while the rules are in; nothing there in training), and a small "Privacy notice" link in `--paper` at 80%. Its measured height is `--machine-h` (`useMachineHeight`), so sheets stop at the platen. Flat fills only.
  - **Keys** (`TypeKey.tsx`): round, 64px, `--ink` cap, 3px `--slate` rim, a `--paper` 24px symbol over an 11px bold word. Held down (Open while choosing a cell) the cap turns `--paper` with an `--ink` legend and sits 2px lower; used up, the legend fades to 40% and the key is dead.
  - **Bars** (`SpaceBar.tsx`): wide square bars like a space bar, 48px tall, 3px border, 14px bold: `--party` fill when the view's primary action, otherwise `--ink` with a `--slate` border and `--paper` text. They hold the screen's actions in place of the keys.
- **Orders:** the typewritten letter from inside the folder (`Briefing.tsx`), a finished document on the desk, never in the typewriter: white `--paper` with a 1.5px `--ink` edge, unfolding from the top with two faint fold creases (`--ink` at 10%), a "TOP SECRET" stamp in the corner and a coffee ring (`CoffeeStain.tsx`, also on the day's last report: translucent `--coffee` at 7–30%, multiplied into the paper, rotated in the top-right corner and running off the top and right edges, clear of the story text), then, already typed: an uppercase letterhead (Operation Blind Spot, "Assignment I of IV · Open floor", Day, From: The Archivist, To: Draughtsman, Planning Office), a dashed rule, the level's backstory as a letter ("Draughtsman," … "— The Archivist"), an "Orders" section numbering the level's brief and its play orders, another dashed rule, and a muted "Destroy after reading" line. The letter takes the desk's spare height and scrolls inside, so its actions stay in view under it as two buttons side by side: "Start operation" (primary) and "How to play", which plays that level's training record and ends with "Back to orders". While a level's rules are new to the player (levels I to III, until its training is filed or skipped) the pair is "Start training" (primary) and "Skip training" instead. Story and orders live in `frontend/src/game/briefings.ts`, one entry per level, in our own words: never Orwell's text, characters or organisations.
- **Open record (`RecordScreen.tsx`):** on the sheet, top to bottom: the letterhead line, the level tabs line, the status row under a dashed rule, the board (all the height left), and the message line just above the platen, three lines high so messages never move the board. About 90px above the board on a phone. On the machine: the three hint keys, or, once the record closes, a primary "Show report" bar, with the sound switch and the "?" (rules card) as the function tabs either side. There is no standing-orders section and no level brief on this screen: the brief is in the orders, and the rules live in the rules card and the training records.
- **Report:** when a record closes, the Archivist's typewritten report is fed into the typewriter in the record's place (`Report.tsx`; the record stays mounted underneath, hidden, so going back doesn't retype it): an uppercase letterhead (Operation Blind Spot, "Report · Assignment II of IV · Corridors", Day, From: The Archivist), a dashed rule, the verdict stamp, a short letter ("Draughtsman," … "— The Archivist", words in `reportLetter` in `briefings.ts`), the result line, and once the day is over the **standing** and the countdown. Its actions are bars on the machine: "Next record" (primary) while another record is open, or "Share result" (primary, copies the share card; the card itself isn't shown on the report) once the day is over, beside a plain "Back to record". The standing (`StandingSection.tsx`) sits under the sign-off: a bold uppercase "Standing" label, a stencil headline in `--ink` ("Top 8% of insiders today." when in the top half, otherwise "Further than 40% of insiders today." after being seen or "Better than 30% of insiders today."), the chart and a score receipt: "Time", then a line per penalty taken ("2 hints +01:00", "1 strike +01:00"), then "Score" under a 1px `--ink` rule, labels in typewriter and values right-aligned in condensed digits. No sentences. The chart (`StandingChart.tsx`) is square bars with 2px gaps on a 1px `--ink` baseline: faint `--ink` at 25%, the player's bar solid `--ink` with a "You" label, a muted caption above and end labels below. After toppling it shows the spread of toppled players' scores, fast on the left; after being seen, how far everyone got (Seen on I … Toppled). No red: it is not the Party's. With too few players it says so instead of a percentage. The reports that end the day ("Seen", "Toppled") carry the coffee ring in the top-right corner; "Rectified" between records does not.
- A level's clock starts only when the player presses "Start operation": never on page load, opening the folder or reading the orders. The letterhead's record number reads "Sealed" until then.
- **Letterhead** (`Letterhead.tsx`), the first typed line of every sheet and of the desk: 12px uppercase typewriter, `letter-spacing: .08em`: "**Surveilled** · Day 34" on the left, "No. 04127" on the right, and the records' date ("24 November 2026", `--muted`) between them where the screen is wider than 420px. Once the government is toppled, a struck-through "~~Ministry of Truth~~" stands in place of the date. In training the right end is "Leave training" (a bold underlined typed button). There is no big wordmark anywhere.
- **Level tabs**, the second typed line (`LevelTabs.tsx`): the four levels as typewriter tab stops, 12px. The current one is typed in an inverted `--ink` box with its name ("IV Ministry of Truth"); the others show only their numeral and the share card's mark: ■ filed, □ seen (in `--party-text`). Locked levels are at 40% and disabled. Each is 44px tall to the finger, and its `aria-label` names the record, its name and its state.
- **Status row** (`StatusStrip.tsx`): one row under a dashed `--ink` rule: "Cameras left" with the count, "Strikes" with three small camera icons (`--party` when taken), "Difficulty" with five squares (the word hides below 420px wide), and the clock at the right end. Labels in typewriter 12px, figures in `--font-digit` 19px. Training shows only the counts.

## Components

- **Buttons:** `--paper` fill, 1.5px `--ink` border, 14px bold body font, square. Primary: `--party` fill and border, `--paper` text, at most one per view.
- **Cookie notice:** a compact `--paper` slip with a 1.5px `--ink` border, in the normal flow (never fixed, never over the board): at the foot of the desk, or on the typewriter's body above the keys (the board gives it the room). One 12px sentence ("Surveilled uses one cookie, to keep your game on our server. No tracking, no ads, no analytics.") with a "Privacy notice" link, and a small plain "Acknowledge" button beside it. It informs; there is no Decline. Once acknowledged it is gone for good in that browser.
- **Links:** `--ink`, underlined (2px on hover), the red keyboard focus outline. Never red (`TextLink.tsx`). On the typewriter's body the privacy link is `--paper` at 80%.
- **Privacy notice page:** `privacy.html`, the same one-column sheet: a muted "Surveilled" eyebrow, "Privacy notice" in stencil, the date, the 3px `--ink` rule, then sections with bold uppercase 13px heads, plain typewriter text and square bullets, and "Back to the game" under a dashed rule. Plain language, not the game's fiction. Every game screen links to it: the desk's footer, or the typewriter's body.
- **Hint keys:** the three round keys on the typewriter, one per kind of hint (`Controls.tsx`, `TypeKey.tsx`): each a 24px symbol over a small word (`HintIcon.tsx`): **Open**, a magnifying glass (the player then taps a hidden or marked cell; a safe cell is cleared, a camera is marked with no strike), **Camera**, the camera icon (outlines a camera), and **Safe**, the camera struck through (outlines a safe cell), each of the last two with what proves it when something does. Never call a safe cell a "blind spot": cameras can still see it. There is no tap mode: a tap clears or selects, the mark gesture marks or stamps. Once taken, a key's word reads "Used" and the key fades and is dead until tomorrow (one of each a day, shared by all four records); in training they never run out. While the player is choosing a cell, the Open key is held down (`--paper` cap, `aria-pressed`) and the message line says "Tap a hidden cell to open it. Tap Open again to cancel."; any other move cancels it. Each `aria-label` says what the hint does and whether it is left ("Hint: show a camera, used today"). None of them is primary.
- **Level tabs:** see the second typed line under Layout. Current tab inverted (`--ink` fill) with `aria-current="true"`.
- **Folder:** a manila file folder (`Folder.tsx`), flat fills mixed from `--dossier` with `--ink` (front cover 7%, back cover and tab 14%) and 1.5px `--ink` edges. The back cover has a file tab top-left reading "Blind Spot"; the white `--paper` orders peek out over the top edge. The front cover is hinged on the left and carries a small "Planning Office" print, a "TOP SECRET" stamp and a pasted `--paper` label ("Ministry of Truth", "Record I of IV", "Day 2 · Eyes only"), each on one line at every width. A `--party` ribbon is tied round the right side, closed with the Ministry's wax seal: a flat `--party` blob with an uneven poured edge and a pressed `--paper` ring, holding the camera icon in `--paper`. It sizes in `cqi`, so it scales with the sheet.
- **Side sheets:** the report and the rules card take the record's place in the typewriter (`useSideSheet`): fed in with the paper feed and its ratchet, starting at the top, scrolling inside when long. Focus moves to the sheet's heading so a screen reader reads it; Escape or "Back to record" (a plain bar on the machine) takes it out, and focus returns to what had it. No overlay, no ×, no dimming.
- **Training screen:** a training record is played on its own sheet in the typewriter (`TrainingScreen.tsx`; the day's typewriter stays mounted underneath, hidden, so the orders don't retype on return). Top to bottom on the sheet: the letterhead line (an inverted `--ink` "Training record II · Walls" in place of the game's name, "Leave training" at its right end), the **training card** (`TrainingCard.tsx`), the status row without clock or difficulty (cameras left and strikes only), the real board and the message line. On the machine: the sound switch and the three hint keys, free ("Free" under each legend). No slides and no Next buttons: the player moves on by playing.
  - **The card:** a `--paper` panel with a 1.5px `--ink` border: a tag, a stencil title and one or two sentences. Tags: **Rule** (a rule of the game, a filled ink chip), **Tip** (outlined) and **Pro tip** (double outline); never red. Each training opens with a card per guided move: the rule, and the move to try it on, with that cell outlined (the hint outline). Until it is made only that move goes through; any other gets one line ("Try it on the outlined cell first.", or how to make the move). Then the card says "Now finish the record" with one tip, and the player plays freely, with real strikes. Filed, it reads "Rectified" over one flat line.
  - **Ending:** filed, the one primary bar on the machine is "Back to orders" (opened from the orders), "Next training" or "Done" (after IV); lost, it is "Try again", which deals the record afresh. Nothing in training is scored, ranked or logged.
  - **Records:** four 5×5 boards drawn by hand on the server (`backend/app/services/training_records.py`), one per level: Basics, Walls, Party records, Combining. Their words are in `frontend/src/game/training.ts`, which names their cells.
  - **Wording:** only cameras see. A cell is "in line with" a number when they share a row or column with no wall between; a number counts the cameras that can see its cell. Never write that a number "sees" anything, in training or in the game's messages.
- **Rules card:** the "?" during a record feeds in a side sheet (`RulesCard.tsx`) titled "Rules": the rules learned so far, one line each with square bullets, grouped under bold uppercase "Record I · Basics" heads up to the current level, and one muted line under a dashed rule ("Practise any time: open How to play from a record's orders."). Nothing to click through.
- **Icon:** the only icon is the CCTV camera (plus the "?" that feeds in the rules card, labelled for screen readers; the hint keys' symbols, a magnifying glass and the camera struck through, in the camera's own line style; and the typewriter's parts, which are drawn decoration) (housing tilted toward the viewer, lens, wall bracket; 24px grid, 2px stroke, `currentColor`), in `frontend/src/components/CameraIcon.tsx`. Don't add icon libraries or other icons; use words.

## Sound

- The only sounds are the office's, synthesised in the browser with Web Audio (`frontend/src/lib/sound.ts`, no audio files; the swells of air draw on two seconds of noise, since a short loop flutters audibly): a typewriter keystroke for every cell typed in (built from short, hard clicks like the shutter: the typebar's impact, a metal clack ringing at two narrow resonances that shift a little with every key, a small knock of the platen and, 28ms later, the escapement's tick), timed to the cell's animation, so a cascade patters (keystrokes closer than 18ms merge, at most 16 a move); a camera shutter when a camera is marked (two quick mechanical clicks); a rubber stamp's thud when a Party record is stamped False (a low thump and a muffled smack, as the stamp lands); a soft tick when a mark or stamp is taken back; a desk lamp switched on when a number is tapped to light up its lines (a soft click, then a faint breath of air rising as the light sweeps out, as long as the sweep) and a softer click when it is let go; the sealed folder opening, timed to its animation (the wax seal cracking: a sharp snap, a few crumbs of wax and a dull give; the manila cover swinging open with a soft flap and a breath of air; the orders sliding out with a dry paper hiss; none of it with reduced motion, where the folder doesn't animate); tapping to finish is silent, and so are the orders under reduced motion); the platen knob's ratchet when a fresh sheet is fed into the typewriter (a low roll and seven soft clicks, only once a tap has woken the audio: a sheet that is simply there on page load is silent); and the carriage bell (a soft inharmonic ding) when a record is filed. Being seen sounds too: the typewriter jams (four typebars crashing together within a few milliseconds, a scrape, and the bell struck sour, two tones a semitone apart). A loss adds a soft police two-tone in the distance (a low, quiet triangle wave, high on red and low on blue), in step with the overlay's lights for their first two cycles, fading out under them. Nothing else makes a sound: no music.
- Sound is on by default and the "Sound on" / "Sound off" switch turns it off, remembered in this browser. Audio is woken inside the tap itself (`wakeSound`), because browsers only let a page start sound from a gesture.

## Copy

- The story: the player is a **draughtsman** in the Ministry's Planning Office who marks the cameras on the Ministry's floor plans, checking doubtful spots in person on their rounds, so the resistance's team can go in unseen; filing level IV is the night they go in. Letters address them "Draughtsman,"; other players are **insiders** (the standings, the share card).
- Fixed vocabulary: the watchers = **cameras** (never telescreens); puzzle = **record**; finishing = **filing**; win = **Rectified**; final win = **Toppled**; loss = **Seen**; the day's four puzzles = **levels** (I to IV); rules = **Standing orders**; red given numbers = **Party records**; uncovered numbers = **your observations**; mistakes = **strikes**; subscription = **Clearance**.
- Buttons: verb first, sentence case ("Open record", "Start operation", "Start training", "Next record", "Share result", "Leave training").
- Never quote Orwell's text. Use the setting in our own words.

  IV  ■ 11:40 · 2 hints
  REGIME TOPPLED · 20:45
  Score 22:45 · top 8% of 1,204 insiders
  Toppled 3 days running

- **Daily records:** the same four records for everyone each day, opening at the player's local midnight. The day number goes in the eyebrow only. A countdown to the next records appears once the day is over.

## Accessibility

- Text contrast at least 4.5:1 (3:1 for 24px+). `--party` text under 24px on `--concrete` must use `--party-text` instead.
- Every cell is a `<button>` with an `aria-label` that includes its state and "row N, column M".
- Support tap, long-press (430ms) and right-click to mark; arrow keys move focus on the board; `m` or `f` marks. Both gestures always work, but help text names only the one for the player's main pointer (`usePointer`, `(pointer: coarse)`): "press and hold it" on touch screens, "right-click it" with a mouse (`MARK_GESTURE` in copy.ts). Words that name the gesture (training cards, the rules card, the orders, the board's messages) are `PointerText`, resolved with `forPointer`.
- Game state lives on the server, keyed by an anonymous httpOnly cookie. The browser keeps only per-viewer conveniences (the toppling streak, the acknowledged cookie notice, which training records were filed or skipped, whether the sound is off) in `localStorage`, always through `frontend/src/lib/storage.ts`, which wraps every access in try/catch.
